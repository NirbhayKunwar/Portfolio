# Personal Portfolio - Nirbhay Singh Kunwar

A modern, responsive personal portfolio website showcasing academic achievements, professional projects, and core technical skills. Built using React, Vite, and custom CSS.

## 🚀 Features

* **Dual View Modes (Vibe Switcher)**: Toggle between **Academic/Professional** mode (Midnight Violet theme, formal copy, research inquiries) and **Casual/Creative** mode (Cyber Cyan theme, project-focused copy, casual inquiries).
* **Theme Customization Matrix**: Floating widget with Light/Dark canvas mode toggles and nine distinct color spectrum presets.
* **Interactive Resume Components**:
  * Glowing neon timeline showing education history.
  * Project portfolio grid showcasing deployed web platforms (ITMS Traffic System and UAHM website).
  * Filterable technical skills grid with interactive detail tooltips.
  * Validated contact form and responsive layout.

## 🛠️ Tech Stack

* **Framework**: React 19
* **Build Tool**: Vite
* **Styling**: Vanilla CSS (custom variables and responsive design)
* **Icons**: Lucide React

## 💻 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed.

### Installation
1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```

### Development
Start the local development server:
   ```bash
   npm run dev
   ```

### Code Formatting & Linting
Run ESLint to check code quality:
   ```bash
   npm run lint
   ```

### Build
Compile the optimized production bundle:
   ```bash
   npm run build
   ```
The output will be generated inside the `dist/` directory.
